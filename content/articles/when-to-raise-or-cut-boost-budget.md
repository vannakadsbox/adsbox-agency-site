- **$10 ក្នុងមួយថ្ងៃ** – មើលសរុបយ៉ាងតិច ៣ ទៅ ៥ ថ្ងៃ

## សំណួរ ៥ មុនប្ដូរថវិកា

**សំណួរទី ១៖ ស្តុកនៅគ្រប់ ហើយ Admin ឆ្លើយទាន់ទេ?**

- **ទេ** → កុំបន្ថែមលុយ។ បន្ថែមលុយពេលស្តុកជិតអស់ ឬ Admin ឆ្លើយមិនទាន់ គឺចាយលុយទិញសារដែលបងបិទមិនបាន។ ដោះស្រាយមុនសិន។
- **បាទ/ចាស** → ទៅសំណួរទី ២។

**សំណួរទី ២៖ Cost per Delivered Order (តាមចំនួនថ្ងៃខាងលើ) ទាបជាងបន្ទាត់ក្រហមទេ?**

- **បាទ/ចាស** → ទៅសំណួរទី ៣។
- **ទេ** → ទៅសំណួរទី ៤។

**សំណួរទី ៣៖ អត្រាដឹកជោគជ័យ និងអត្រាបិទ Order នៅស្ថិរភាពដូច ៧ ថ្ងៃមុនទេ?**

- **បាទ/ចាស** → **សាកបន្ថែមថវិកាបន្តិច** ប្រហែល 20% ទៅ 30% (ឧទាហរណ៍ $10 → $12 ឬ $13)។ 20–30% គឺជា guideline សម្រាប់ការសាកល្បងរបស់ ADS BOX មិនមែនជា Meta rule ហើយអាចត្រូវកែតាមទំហំ account និងលទ្ធផលជាក់ស្តែង។ បន្ទាប់មក រង់ចាំយ៉ាងហោចណាស់ ៣ ថ្ងៃ ឬរង់ចាំរហូតមានទិន្នន័យគ្រប់គ្រាន់សម្រាប់ប្រៀបធៀប មុនបន្ថែមម្ដងទៀត។
- **ទេ ធ្លាក់** → **រក្សាថវិកាដដែល** ហើយកែចំណុចដែលធ្លាក់សិន។ Order ច្រើនឡើង តែមិនទទួលច្រើនឡើង មិនមែនជាការរីកចម្រើនទេ។

**សំណួរទី ៤៖ លុយលេចនៅជំហានណា?**

ប្រៀបធៀបជាមួយ ៧ ថ្ងៃមុនរបស់បងខ្លួនឯង ដោយប្រើ **ADS BOX Decision Matrix** ខាងក្រោម។ ពេលរកឃើញហើយ កែតែរឿងមួយក្នុងមួយពេល រួចរង់ចាំយ៉ាងហោចណាស់ ៣ ថ្ងៃ ឬរង់ចាំរហូតមានទិន្នន័យគ្រប់គ្រាន់សម្រាប់ប្រៀបធៀប។

**សំណួរទី ៥៖ លើសបន្ទាត់ក្រហមឆ្ងាយ ច្រើនថ្ងៃជាប់គ្នាទេ?**

- **បាទ/ចាស** (ឧទាហរណ៍ លើសទ្វេដង ពេញរយៈពេលដែលបងមើល ទាំងបានកែហើយ) → **ផ្អាក Post នោះ** ហើយយកលុយទៅសាក Post ថ្មី
- **ទេ** → កាត់ថវិកាបន្តិច ឬរក្សា ខណៈកំពុងកែចំណុចដែលរកឃើញក្នុងសំណួរទី ៤

## ADS BOX Decision Matrix

នេះជាក្របខណ្ឌវិនិច្ឆ័យដែល ADS BOX ប្រើ ដើម្បីរកកន្លែងដែលលុយលេច។ វាមិនមែនជាច្បាប់ទូទៅ ឬច្បាប់របស់ Facebook ទេ៖

- **Cost per Message ឡើង** → ពិនិត្យ Post៖ រូប វីដេអូ Caption
- **សារនៅធម្មតា តែអត្រាបិទ Order ធ្លាក់** → ពិនិត្យ Messenger៖ ល្បឿនឆ្លើយ តម្លៃ និងថ្លៃដឹកច្បាស់ឬអត់
- **Order នៅធម្មតា តែអត្រាដឹកជោគជ័យធ្លាក់** → ពិនិត្យការបញ្ជាក់ Order និងការដឹក
- **ការដឹកនៅធម្មតា តែ Cost per Delivered Order ឡើង** → ពិនិត្យការផ្ដល់ជូន តម្លៃ និងចំណេញរបស់ទំនិញ ឬ Post
- **Order ល្អ តែចំណេញទាប** → ពិនិត្យថ្លៃដើម តម្លៃលក់ និង Promotion
- **ចំណេញល្អ ហើយការដឹកនៅស្ថិរភាព** → អាចសាកបន្ថែមថវិកាបន្តិចដោយគ្រប់គ្រង

## ឧទាហរណ៍សម្រាប់បង្ហាញវិធីគណនា

ហាងកាបូបមួយ (មិនមែនទិន្នន័យអតិថិជនពិត) លក់កាបូប $15។ ឧទាហរណ៍នេះសន្មត់ថា ក្រោយដកថ្លៃដើម ថ្លៃខ្ចប់ និងថ្លៃ Order មិនទទួលជាមធ្យម ហាងនៅសល់ចំណេញមុនដក Boost ប្រហែល $8 ក្នុងមួយកាបូបដែលដឹកដល់។ ម្ចាស់ហាងចង់ឲ្យកាបូបនីមួយៗនៅសល់ចំណេញយ៉ាងតិច $4 ដូច្នេះ **បន្ទាត់ក្រហម = $8 − $4 = $4 ក្នុងមួយ Order ដែលដឹកដល់**។

**៣ ថ្ងៃដំបូង (Boost $10 ក្នុងមួយថ្ងៃ)៖** ចាយ $30 Order ១៦ ដឹកដល់ហើយបានលុយ ១២។

- Cost per Order = $30 ÷ ១៦ ≈ $1.88
- Cost per Delivered Order = $30 ÷ ១២ = $2.50 → ទាបជាងបន្ទាត់ក្រហម $4
- អត្រាដឹកជោគជ័យ = ១២ ÷ ១៦ = 75%
- ស្តុកនៅ Admin ឆ្លើយទាន់ អត្រាបិទ Order ស្ថិរភាព → **សាកបន្ថែមទៅ $12 ក្នុងមួយថ្ងៃ**

**៣ ថ្ងៃបន្ទាប់ (Boost $12 ក្នុងមួយថ្ងៃ)៖** ចាយ $36 Order ១៧ ដឹកដល់ហើយបានលុយ ១១។

- Cost per Order = $36 ÷ ១៧ ≈ $2.12
- Cost per Delivered Order = $36 ÷ ១១ ≈ $3.27 → នៅក្រោម $4
- តែអត្រាដឹកជោគជ័យ ធ្លាក់មក ១១ ÷ ១៧ ≈ 65%
- សំណួរទី ៣ ឆ្លើយថា «ទេ» → **រក្សា $12** ហើយផ្ញើសារបញ្ជាក់ Order មុនខ្ចប់គ្រប់ Order មុនគិតបន្ថែមទៀត

បើមើលតែ Cost per Order ($2.12) ម្ចាស់ហាងអាចគិតថាគួរបន្ថែមលុយទៀត។ តែលេខដឹកដល់ ប្រាប់ថាត្រូវកែការបញ្ជាក់ Order សិន។
