បងៗ ជ្រើសរូបដែលខ្លួនចូលចិត្តជាងគេ Boost ហើយសង្ឃឹមថាលក់ដាច់។ ពេលលក់មិនដាច់ ក៏មិនដឹងថាខុសនៅរូប តម្លៃ ឬ Caption។ ពេលលក់ដាច់ ក៏មិនដឹងថាត្រូវធ្វើម្ដងទៀតយ៉ាងម៉េចដែរ។

វិធីដែលច្បាស់ជាងការទាយ គឺ **សាកល្បង Boost Post ពីរ** ដែលខុសគ្នាតែរឿងមួយ ហើយវាស់ថាមួយណានាំ Order ដែលដឹកដល់ច្រើនជាង ក្នុងលុយដូចគ្នា។

## ជំហានទី ១៖ ជ្រើសរឿងតែមួយ ដែលបងចង់សាក

Post ទាំងពីរត្រូវដូចគ្នាស្ទើរទាំងអស់ ខុសគ្នាតែរឿងមួយ។ ឧទាហរណ៍៖

- **រូបភាព៖** អាវដាក់លើតុ ទល់នឹងមនុស្សពាក់អាវនោះ
- **Caption៖** Caption ខ្លី ទល់នឹង Caption ប្រាប់ទំហំ សាច់ក្រណាត់ និងថ្លៃដឹក
- **តម្លៃ៖** ដាក់តម្លៃក្នុង Caption ទល់នឹងឲ្យភ្ញៀវឆាតសួរ
- **ការផ្ដល់ជូន៖** បញ្ចុះ $2 ទល់នឹងដឹកឥតគិតថ្លៃ

បើប្ដូរពីរបីរឿងក្នុងពេលតែមួយ ទោះ Post មួយឈ្នះ ក៏បងមិនដឹងថាឈ្នះដោយសាររឿងណា។

## ជំហានទី ២៖ ដាក់លក្ខខណ្ឌ Boost ដូចគ្នា

- ថវិកាប្រចាំថ្ងៃដូចគ្នា
- Audience ដូចគ្នា (អាយុ ទីតាំង ចំណាប់អារម្មណ៍)
- ចាប់ផ្ដើមថ្ងៃ និងម៉ោងប្រហាក់ប្រហែលគ្នា
- រយៈពេលដូចគ្នា ហើយកុំកែ Post ពេលកំពុងសាក

## ជំហានទី ៣៖ កត់លេខដល់ Order ដែលដឹកដល់

Like និងសារច្រើន មិនប្រាកដថាលក់បានច្រើនទេ។ សម្រាប់ Post នីមួយៗ កត់៖ លុយចាយ សារ Order Order បញ្ជាក់ និងដឹកដល់ហើយបានលុយ។

ដើម្បីដឹងថាភ្ញៀវមកពី Post ណា ដាក់ Label ឈ្មោះ Post ក្នុង Messenger ពេលបិទ Order។ របៀបកត់មាននៅក្នុង [របាយការណ៍ Boost ប្រចាំថ្ងៃ](/knowledge/daily-spend-and-order-report/)។

## ជំហានទី ៤៖ រង់ចាំទិន្នន័យឲ្យគ្រប់

កុំសម្រេចចិត្តពីប៉ុន្មានម៉ោងដំបូង។ បើ Post នីមួយៗទើបមាន Order តិចជាងដប់ ការខុសគ្នាមួយ ឬពីរ Order អាចមកពីចៃដន្យ។ ក្នុងករណីនោះ សាកបន្តថ្ងៃទៀត មុនសម្រេចចិត្ត។

## ជំហានទី ៥៖ ប្រៀបធៀបដោយ Cost per Delivered Order

- **Cost per Delivered Order** = លុយចាយ ÷ ចំនួន Order ដែលដឹកដល់ហើយបានលុយ
- Post ដែលមាន Cost per Delivered Order ទាបជាង ក្នុងលក្ខខណ្ឌដូចគ្នា ទំនងជា Post ល្អជាង
- បើលេខស្ទើរដូចគ្នា មិនទាន់មានអ្នកឈ្នះច្បាស់ទេ៖ សាកបន្ត ឬសាករឿងថ្មី

## ឧទាហរណ៍សម្រាប់បង្ហាញវិធីគណនា

ហាងអាវយឺតនារីមួយ (មិនមែនទិន្នន័យអតិថិជនពិត) Boost Post ពីរ ដែលមាន Caption និងតម្លៃដូចគ្នា ខុសគ្នាតែរូប៖

- **Post A៖** រូបអាវ ៣ ពណ៌ ដាក់លើផ្ទៃពណ៌ស
- **Post B៖** រូបមនុស្សពាក់អាវ ក្នុងពន្លឺធម្មជាតិ

Post នីមួយៗ Boost $5 ក្នុងមួយថ្ងៃ រយៈពេល ៤ ថ្ងៃ (សរុប $20)៖

- **Post A៖** សារ ៤០ · Order ១២ · ដឹកដល់ហើយបានលុយ ៨ → Cost per Order ≈ $1.67 · Cost per Delivered Order = $2.50
- **Post B៖** សារ ២៥ · Order ១១ · ដឹកដល់ហើយបានលុយ ១០ → Cost per Order ≈ $1.82 · Cost per Delivered Order = $2.00

បើមើលតែសារ ឬ Cost per Order Post A ហាក់ដូចជាឈ្នះ។ តែបើមើល Order ដែលដឹកដល់ Post B ល្អជាង៖ ភ្ញៀវឃើញអាវពាក់លើខ្លួនពិត ទំនងជាដឹងច្បាស់ពីអ្វីដែលខ្លួនទិញ ហើយមិនសូវប្ដូរចិត្តពេលទទួល។ នេះជាការសន្និដ្ឋានពីឧទាហរណ៍មួយ មិនមែនច្បាប់សម្រាប់គ្រប់ទំនិញទេ។

1. ផ្អាក ឬបន្ថយ Post ដែលចាញ់

4. ចាប់ផ្ដើមសាករឿងថ្មីមួយទៀត ដូចជា Caption ឬការផ្ដល់ជូន

លទ្ធផលពីការសាកល្បងមួយដង មិនមែនច្បាប់ជាប់រហូតទេ។ ទំនិញ រដូវ និងតម្លៃផ្សេងគ្នា អាចផ្ដល់លទ្ធផលខុសគ្នា។
