## សប្ដាហ៍ទី ៣ (ថ្ងៃ ១៥–២១)៖ Boost តូចៗ លើ Post ដែលល្អជាងគេ

រាល់ព្រឹក កត់លេខមួយជួរ៖ លុយចាយ សារ Order Order បញ្ជាក់ ដឹកដល់ និងមិនទទួល។ កុំប្ដូរ Post ឬថវិការាល់ថ្ងៃ ទុកពេលឲ្យលេខមានន័យសិន។

## សប្ដាហ៍ទី ៤ (ថ្ងៃ ២២–៣០)៖ វាស់លេខដល់ចំណេញ ហើយសម្រេចចិត្ត

Order មិនទាន់ជាចំណេញទេ។ លុយត្រូវដើរឆ្លងផ្លូវនេះ៖ លុយចាយ → Message → Order → Confirmed → Delivered → Paid → Profit។ ពន្យល់លម្អិតនៅក្នុង [គណនាពីលុយចាយ Boost ដល់ចំណេញពិត](/knowledge/cost-per-message-vs-cost-per-order/)។

**ឧទាហរណ៍សម្រាប់បង្ហាញវិធីគណនា** (មិនមែនទិន្នន័យអតិថិជនពិត)៖ ហាងថ្មីមួយលក់អាវ $12 ក្នុងមួយឈុត ថ្លៃដើម $6។ ក្នុងសប្ដាហ៍ទី ៣–៤ ហាង Boost អស់ $30 បានសារ ៦០ Order ១២ បញ្ជាក់ ១០ ដឹកដល់ហើយបានលុយ ៩ និងមិនទទួល ១។ ឧទាហរណ៍នេះសន្មត់ថា ថ្លៃខ្ចប់ $0.30 ហាងចេញថ្លៃដឹក $1.50 និងថ្លៃដឹកត្រឡប់ $1.50។

1. Cost per Message៖ $30 ÷ ៦០ = **$0.50**
2. លុយ Boost ក្នុងមួយ Order ដឹកដល់៖ $30 ÷ ៩ ≈ **$3.33**
3. ចំណេញមុន Boost ក្នុងមួយ Order ដឹកដល់៖ $12 − $6 − $0.30 − $1.50 = **$4.20** ហើយ ៩ × $4.20 = **$37.80**
4. ដក Boost៖ $37.80 − $30 = $7.80
5. ដកកញ្ចប់មិនទទួល ១៖ $0.30 + $1.50 + $1.50 = $3.30 ហើយ $7.80 − $3.30 = **$4.50**

$4.50 នេះជាចំណេញមុនដកថ្លៃថេរ (contribution profit) មិនទាន់ដកថ្លៃផ្ទះ ទឹកភ្លើង ឬម៉ោងធ្វើការរបស់បងទេ។ វាតូច តែជាលេខពិត ដែលប្រាប់ថាត្រូវកែត្រង់ណា។
