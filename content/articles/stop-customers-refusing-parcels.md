បងៗ ធ្លាប់ទេ? ភ្ញៀវ Inbox មកកុម្ម៉ង់ យើងខ្ចប់រួច ផ្ញើទៅដល់ ស្រាប់តែភ្ញៀវថា «មិនយកទេ» ឬទូរស័ព្ទមិនលើក។ ឥវ៉ាន់ត្រឡប់មកវិញ បងខាតថ្លៃដឹក ពេលវេលា ហើយទំនិញខ្លះខូចកញ្ចប់ទៀត។

អត្ថបទនេះជួយបងគណនាថា Order មិនទទួលមួយ ខាតប៉ុន្មានពិតៗ ហើយប្រើវិធី ៤ ដែលហាងតូចធ្វើបានភ្លាម ដើម្បីកាត់បន្ថយវា។

## ហេតុអ្វីភ្ញៀវមិនទទួល?

ជាញឹកញាប់ មិនមែនមកពីភ្ញៀវអាក្រក់ទេ។ ភ្ញៀវខ្លះកុម្ម៉ង់ពេលរំភើប ហើយភ្លេច។ ខ្លះច្រឡំទំហំ ឬពណ៌។ ខ្លះរង់ចាំយូរពេក ក៏ទៅទិញផេកផ្សេង។ ខ្លះទៀតមិនដឹងថាត្រូវបង់ប៉ុន្មានពេលទទួល។

## Order មិនទទួលមួយ ខាតប៉ុន្មាន?

ថ្លៃនៃ Order មិនទទួលមួយ មិនមែនតែថ្លៃដឹកទេ៖

> ថ្លៃដឹកទៅ និងដឹកត្រឡប់ដែលហាងត្រូវបង់
> + ថ្លៃខ្ចប់ដែលខាតចោល
> + លុយ Boost ដែលបានចាយដើម្បីបាន Order នោះ
> = ថ្លៃនៃ Order មិនទទួលមួយ

មិនទាន់គិតពេល Admin ពេលខ្ចប់ និងស្តុកដែលជាប់នៅក្រៅប៉ុន្មានថ្ងៃ ដែលមិនអាចលក់ឲ្យភ្ញៀវផ្សេងបាន។

**តាមដានលេខមួយនេះរាល់សប្ដាហ៍៖**

- **អត្រាដឹកជោគជ័យ** = ចំនួនដឹកដល់ហើយបានលុយ ÷ ចំនួន Order

គ្មានលេខមួយដែលល្អសម្រាប់គ្រប់ហាងទេ ព្រោះវាអាស្រ័យលើទំនិញ តំបន់ដឹក និងប្រភេទភ្ញៀវ។ សូមប្រៀបធៀបជាមួយសប្ដាហ៍មុនៗរបស់បងខ្លួនឯង។

## ឧទាហរណ៍សម្រាប់បង្ហាញវិធីគណនា

ហាងខោអាវមួយ (មិនមែនទិន្នន័យអតិថិជនពិត)។ ឧទាហរណ៍នេះសន្មត់ថា ថ្លៃ Order មិនទទួល = $2 ថ្លៃខ្ចប់ = $0.30 និងលុយ Boost ប្រហែល $1.67 ក្នុងមួយ Order។ តម្លៃពិតអាស្រ័យលើក្រុមហ៊ុនដឹក និងលក្ខខណ្ឌរបស់ហាង។

- ថ្លៃនៃ Order មិនទទួលមួយ = $2 + $0.30 + $1.67 = $3.97
- ក្នុងមួយខែ ហាងមាន Order ១០០ មិនទទួល ១៥ → ខាតប្រហែល ១៥ × $3.97 ≈ $60
- អត្រាដឹកជោគជ័យ = ៨៥ ÷ ១០០ = 85%

បើហាងនេះចាប់ផ្ដើមបញ្ជាក់ Order មុនខ្ចប់ ហើយមិនទទួលធ្លាក់មក ៨ (ឧទាហរណ៍) ការខាតនឹងនៅប្រហែល ៨ × $3.97 ≈ $32 គឺសន្សំបានប្រហែល $28 ក្នុងមួយខែ ពីទម្លាប់តូចមួយ។

## វិធីទី ១៖ សរុប Order ឲ្យភ្ញៀវបញ្ជាក់មុនខ្ចប់

ពេលភ្ញៀវថា «យក» កុំខ្ចប់ភ្លាម។ ផ្ញើសារសរុបមួយ៖ ទំនិញ ទំហំ ពណ៌ ចំនួន តម្លៃ ថ្លៃដឹក និងតម្លៃសរុបដែលត្រូវបង់ពេលទទួល។ សុំឲ្យភ្ញៀវឆ្លើយ «បាទ» ឬ «ចាស» មុនខ្ចប់។

ឧទាហរណ៍សារ៖

> «បងបញ្ជាក់ Order ណា៖ អាវយឺតខ្មៅ ទំហំ L ១ ឈុត $12 ថ្លៃដឹក $1.5 សរុប $13.5 បង់ពេលទទួល ដឹកដល់ថ្ងៃស្អែក។ ត្រឹមត្រូវទេបង?»

## វិធីទី ២៖ ផ្ញើសារបញ្ជាក់ម្ដងទៀតមុនដឹក

ពេលប្រគល់ឥវ៉ាន់ឲ្យក្រុមហ៊ុនដឹក ផ្ញើសារខ្លីមួយ៖ ឥវ៉ាន់ចេញហើយ ប្រហែលដល់ពេលណា ហើយសុំឲ្យទុកទូរស័ព្ទបើក។ បើភ្ញៀវប្ដូរចិត្ត បងដឹងមុនឥវ៉ាន់ចេញឆ្ងាយ។

## វិធីទី ៣៖ ប្រាប់ថ្ងៃដល់ឲ្យច្បាស់ ហើយដឹកឲ្យលឿន

## វិធីទី ៤៖ សុំកក់មុន តែពេលចាំបាច់
