បងៗ ធ្លាប់ទេ? Boost មួយថ្ងៃ $20 សារចូល ៥០ ថោកណាស់ Order ក៏ចូលច្រើន។ តែដល់ចុងខែ រាប់លុយទៅ មិនសល់ដូចដែលគិតសោះ។

បញ្ហាជាញឹកញាប់ មិនមែនមកពី Boost ខុសទាំងស្រុងទេ។ គឺមកពីយើងឈប់រាប់ត្រឹម **Order** ហើយគិតថា Order គឺជាចំណេញ។ តាមពិត Order មួយ ត្រូវឆ្លងកាត់ជំហានជាច្រើនទៀត ទើបក្លាយជាលុយនៅក្នុងដៃ។

## លុយ Boost ធ្វើដំណើរ ៧ ជំហាន

1. **លុយចាយ** – លុយ Boost ក្នុង Ads Manager
2. **Message** – មនុស្សឆាតមកសួរ
3. **Order** – ភ្ញៀវថា «យក»
4. **Confirmed Order** – ភ្ញៀវបញ្ជាក់ទំនិញ ទំហំ តម្លៃ និងអាសយដ្ឋានរួច
5. **Delivered Order** – ឥវ៉ាន់ដល់ដៃភ្ញៀវ
6. **Paid Order** – លុយ COD ឬលុយផ្ទេរ ABA / KHQR ចូលមកដល់បងពិតៗ
7. **Profit** – លុយដែលនៅសល់ ក្រោយដកថ្លៃទាំងអស់

រៀងរាល់ជំហាន លុយអាចលេចបាត់បន្តិច៖ សារសួរលេង ភ្ញៀវប្ដូរចិត្ត ទូរស័ព្ទមិនលើក ឥវ៉ាន់ត្រឡប់មកវិញ ឬភ្នាក់ងារដឹកមិនទាន់ផ្ទេរលុយ។ ដូច្នេះត្រូវចាំ៖

- Order ≠ Delivered Order
- Delivered Order ≠ Paid Order
- លុយលក់ ≠ ចំណេញ

## អ្វីដែលត្រូវកត់រាល់ថ្ងៃ

Ads Manager ប្រាប់លុយចាយ និងចំនួនសារ តែមិនដឹងថាភ្ញៀវណាបញ្ជាក់ ដឹកដល់ ឬបង់លុយទេ។ លេខទាំងនោះ បង ឬ Admin ត្រូវកត់ខ្លួនឯង សម្រាប់ Post នីមួយៗ ឬ Live នីមួយៗ៖

- **លុយចាយ** – ពី Ads Manager
- **ចំនួនសារថ្មី** – ពី Ads Manager ឬ Messenger
- **ចំនួន Order** – ភ្ញៀវថាយក
- **ចំនួន Order បញ្ជាក់** – ភ្ញៀវឆ្លើយបញ្ជាក់សារសរុប Order
- **ចំនួនដឹកដល់ ហើយបានលុយ** – ពីបញ្ជីក្រុមហ៊ុនដឹក
- **ចំនួនមិនទទួល ឬលុបចោល**

គន្លឹះ៖ ពេលបិទ Order ដាក់ Label ឈ្មោះ Post ក្នុង Messenger ដើម្បីដឹងថាភ្ញៀវមកពី Post ណា។

## គណនាលេខ ៥

- **Cost per Message** = លុយចាយ ÷ ចំនួនសារ
- **អត្រាបិទ Order** = ចំនួន Order ÷ ចំនួនសារ
- **អត្រាដឹកជោគជ័យ** = ចំនួនដឹកដល់ហើយបានលុយ ÷ ចំនួន Order
- **Cost per Order** = លុយចាយ ÷ ចំនួន Order
- **Cost per Delivered Order** = លុយចាយ ÷ ចំនួន Order ដែលដឹកដល់ហើយបានលុយ

Cost per Order ល្អសម្រាប់មើលរហ័សរាល់ថ្ងៃ។ តែពេលសម្រេចចិត្តដាក់លុយបន្ថែម ឬបិទ Post សូមប្រើ **Cost per Delivered Order** ព្រោះវាជិតលុយពិតជាង។

## ចំណេញពីរកម្រិត កុំលាយគ្នា

**ទី ១៖ ចំណេញមុនដកថ្លៃថេរ (Contribution profit)** – គណនាតាម Post តាម Live ឬតាមថ្ងៃ ដើម្បីដឹងថា Boost នោះនៅសល់លុយឬអត់៖

> លុយលក់នៃ Order ដែលបានលុយ
> − ថ្លៃដើមទំនិញ
> − ថ្លៃដឹកដែលហាងចេញ
> − ថ្លៃខ្ចប់
> − ថ្លៃ Order បោះបង់ (ដឹកទៅ ដឹកត្រឡប់ ខ្ចប់ចោល)
> − លុយ Boost
> = ចំណេញមុនដកថ្លៃថេរ

**ទី ២៖ ចំណេញសុទ្ធ (Net profit)** – គណនាម្ដងក្នុងមួយខែ ដើម្បីដឹងថាហាងទាំងមូលចំណេញឬអត់៖

> ចំណេញមុនដកថ្លៃថេរ សរុបពេញមួយខែ
> − ថ្លៃថេរ (ប្រាក់ខែ Admin ថ្លៃផ្ទះ ថ្លៃភ្លើង កម្មវិធី…)
> = ចំណេញសុទ្ធ

កុំដកប្រាក់ខែ ឬថ្លៃភ្លើងចូលក្នុង Order នីមួយៗ ព្រោះលុយទាំងនេះត្រូវបង់ដដែល ទោះ Boost ឬមិន Boost។ ប្រើកម្រិតទី ១ ដើម្បីសម្រេចរឿង Boost ហើយប្រើកម្រិតទី ២ ដើម្បីដឹងថាអាជីវកម្មទាំងមូលនៅសល់លុយឬអត់។

## ឧទាហរណ៍សម្រាប់បង្ហាញវិធីគណនា

ហាងខោអាវមួយ (មិនមែនទិន្នន័យអតិថិជនពិត) លក់អាវ $12 ក្នុងមួយឈុត ថ្លៃដើម $6។ ភ្ញៀវបង់ថ្លៃដឹកខ្លួនឯងពេលទទួល។ បើភ្ញៀវមិនទទួល អាវត្រឡប់មកលក់បានវិញ។

ឧទាហរណ៍នេះសន្មត់ថា ថ្លៃ Order មិនទទួល = $2 និងថ្លៃខ្ចប់ = $0.30 សម្រាប់គោលបំណងបង្ហាញវិធីគណនា។ តម្លៃពិតអាស្រ័យលើក្រុមហ៊ុនដឹក និងលក្ខខណ្ឌរបស់ហាង។

ឥឡូវ ស្រមៃថា Post ដដែល Order ១២ ដដែល តែការបញ្ជាក់ និងការដឹកធ្វើមិនបានល្អ៖ បញ្ជាក់ ១០ ដដែល តែដឹកដល់ហើយបានលុយតែ ៦ មិនទទួល ៤។

Cost per Order នៅតែ $1.67 ដូចមុន តែចំណេញមុនដកថ្លៃថេរធ្លាក់ពី $21 មក $5។ ដូច្នេះ Cost per Order តែមួយ មិនអាចប្រាប់ថា Boost ចំណេញ ឬខាតបានទេ។

- **អត្រាដឹកជោគជ័យ** – បើវាធ្លាក់ Cost per Order ថោកក៏គ្មានន័យ

## ADS BOX Decision Matrix

នេះជាក្របខណ្ឌវិនិច្ឆ័យដែល ADS BOX ប្រើ ដើម្បីរកកន្លែងដែលលុយលេច។ វាមិនមែនជាច្បាប់ទូទៅ ឬច្បាប់របស់ Facebook ទេ ហើយត្រូវមើលជាមួយលេខ ៣ ទៅ ៧ ថ្ងៃរបស់បង៖

- **Cost per Message ឡើង** → ពិនិត្យ Post៖ រូប វីដេអូ Caption
- **សារនៅធម្មតា តែអត្រាបិទ Order ធ្លាក់** → ពិនិត្យ Messenger៖ ល្បឿន និងរបៀបឆ្លើយ
- **Order នៅធម្មតា តែអត្រាដឹកជោគជ័យធ្លាក់** → ពិនិត្យការបញ្ជាក់ Order និងការដឹក
- **ការដឹកនៅធម្មតា តែ Cost per Delivered Order ឡើង** → ពិនិត្យការផ្ដល់ជូន តម្លៃ និងចំណេញរបស់ទំនិញ ឬ Post
- **Order ល្អ តែចំណេញទាប** → ពិនិត្យថ្លៃដើម តម្លៃលក់ និង Promotion
- **ចំណេញល្អ ហើយការដឹកនៅស្ថិរភាព** → អាចសាកបន្ថែមថវិកាបន្តិចដោយគ្រប់គ្រង

## កំហុសដែលគួរជៀស

- រាប់ Order ដែលភ្ញៀវទើបថា «យក» ជាការលក់រួចហើយ
- សម្រេចបិទ ឬបន្ថែមលុយ ដោយមើលតែ Cost per Message
- ភ្លេចថ្លៃ Order មិនទទួល ព្រោះវាមិនបង្ហាញក្នុង Ads Manager
- លាយប្រាក់ខែ និងថ្លៃភ្លើង ចូលក្នុងការគណនា Post នីមួយៗ
- យកលេខ Cost per Order របស់ហាងផ្សេងមកប្រៀបធៀប ទាំងដែលទំនិញ និងចំណេញខុសគ្នា

## Checklist រហ័ស

- ☐ កត់លុយចាយ សារ Order បញ្ជាក់ ដឹកដល់ មិនទទួល តាម Post
- ☐ គណនា Cost per Delivered Order រៀងរាល់សប្ដាហ៍
- ☐ ដឹងចំណេញមុនដក Boost ក្នុងមួយ Order ដែលដឹកដល់
- ☐ គណនាចំណេញសុទ្ធម្ដងក្នុងមួយខែ ក្រោយដកថ្លៃថេរ
- ☐ ប្រៀបធៀបជាមួយ ៧ ថ្ងៃចុងក្រោយរបស់បងខ្លួនឯង

## ពេលណាអាចបន្ថែមថវិកា
