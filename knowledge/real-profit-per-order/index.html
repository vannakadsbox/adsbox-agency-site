រូបមន្តចំណេញមួយ Order

ចំណេញមួយ Order ដឹកដល់ (មុនដកថ្លៃថេរ) = តម្លៃលក់ − ថ្លៃដើមទំនិញ − ថ្លៃខ្ចប់ − ថ្លៃដឹកដែលហាងចេញ − លុយ Boost ក្នុងមួយ Order ដឹកដល់ − ការខាតពី Order មិនទទួល ក្នុងមួយ Order ដឹកដល់

  • លុយ Boost ក្នុងមួយ Order ដឹកដល់ = លុយ Boost សរុប ÷ ចំនួន Order ដែលដឹកដល់ហើយបានលុយ
  • ការខាតពី Order មិនទទួល = ចំនួនកញ្ចប់មិនទទួល × (ថ្លៃខ្ចប់ + ថ្លៃដឹកទៅ + ថ្លៃដឹកត្រឡប់) ÷ ចំនួន Order ដឹកដល់

លេខនេះជាចំណេញមុនដកថ្លៃថេរ ដូចជា ថ្លៃផ្ទះ ប្រាក់ខែបុគ្គលិក និងទឹកភ្លើង។ ចំណេញសុទ្ធ គឺនៅសល់ក្រោយដកថ្លៃថេរទាំងនោះទៀត។

គណនាជាមួយគ្នា ជំហានម្ដងៗ

ឧទាហរណ៍សម្រាប់បង្ហាញវិធីគណនា (មិនមែនទិន្នន័យអតិថិជនពិត)៖ ហាងមួយលក់អាវ $12 ក្នុងមួយឈុត ថ្លៃដើម $6។ ក្នុងមួយខែ ហាង Boost អស់ $60 បាន Order បញ្ជាក់ ៤០ ដឹកដល់ហើយបានលុយ ៣២ និងភ្ញៀវមិនទទួល ៨។ ឧទាហរណ៍នេះសន្មត់ថា ថ្លៃខ្ចប់ $0.30 ក្នុងមួយកញ្ចប់ ហាងចេញថ្លៃដឹក $1.50 ហើយកញ្ចប់មិនទទួល ត្រូវបង់ថ្លៃដឹកត្រឡប់ $1.50 ទៀត។

  1. លុយ Boost ក្នុងមួយ Order ដឹកដល់៖ $60 ÷ ៣២ ≈ $1.88
  2. ការខាតពី Order មិនទទួល៖ ៨ × ($0.30 + $1.50 + $1.50) = $26.40 ហើយ $26.40 ÷ ៣២ ≈ $0.83
  3. ចំណេញមួយ Order ដឹកដល់៖ $12 − $6 − $0.30 − $1.50 − $1.88 − $0.83 ≈ $1.50

ពិនិត្យលេខសរុប៖ ៣២ Order × $1.50 = $48 ក្នុងមួយខែ មុនដកថ្លៃថេរ។ មិនមែន $240 ដូចលេខក្នុងក្បាលទេ។
