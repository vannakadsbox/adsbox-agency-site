៣១ តុលា ២០២៦

របៀបរៀបចំលេខកូដទំនិញសម្រាប់ Facebook Live ឲ្យអតិថិជន Comment កុម្ម៉ង់បានលឿន ហើយ Admin កត់ Order មិនច្រឡំទំហំ ឬពណ៌។

ពេល Live ម្ដងៗ អតិថិជនច្រើននាក់ Comment ក្នុងពេលតែមួយ៖ «យកមួយ», «អាវខៀវនោះប៉ុន្មាន?», «យកដូចបងមុន»។ បើគ្មាន លេខកូដទំនិញពេល Live ច្បាស់លាស់ទេ Admin ពិបាកដឹងថាអតិថិជនចង់បានមួយណា ហើយ Order ងាយខុស។

លេខកូដល្អ ធ្វើឲ្យអ្នកមើលកុម្ម៉ង់បានក្នុងមួយវិនាទី ហើយក្រុមការងារកត់ត្រាបានត្រឹមត្រូវ។ ខាងក្រោមនេះជាគន្លឹះ ៥ ដែលអ្នកអាចចាប់ផ្ដើមប្រើបាននៅ Live បន្ទាប់។

១. ប្រើកូដខ្លី វាយងាយលើទូរស័ព្ទ

កូដល្អគួរមាន ២ ទៅ ៤ តួ ដូចជា A1, A2, B5។ ជៀសវាងកូដវែងៗ ឬអក្សរខ្មែរដែលត្រូវប្ដូរក្ដារចុចច្រើនដង។

អក្សរ និងលេខឡាតាំង វាយលឿនជាងលើទូរស័ព្ទ ហើយអានងាយទោះអេក្រង់តូចក៏ដោយ។ កុំប្រើអក្សរដែលមើលទៅស្រដៀងលេខ ដូចជា O និង 0 ឬ I និង 1។

២. ចែកកូដតាមប្រភេទទំនិញ

ឲ្យអក្សរនីមួយៗតំណាងប្រភេទមួយ ឧទាហរណ៍៖

  • A = អាវ
  • K = ខោ
  • S = ស្បែកជើង
  • B = កាបូប

បែបនេះ ពេលឃើញ Comment «K3» Admin ដឹងភ្លាមថាជាខោ ហើយអ្នកខ្ចប់ក៏រកទំនិញបានលឿនដែរ។

៣. ដាក់ទំហំ និងពណ៌ក្នុង Comment តែមួយ

បញ្ហាធំបំផុតពេល Live គឺអតិថិជនភ្លេចប្រាប់ទំហំ ឬពណ៌ ហើយ Admin ត្រូវឆាតសួរម្ដងទៀត។ ដោះស្រាយដោយកំណត់ទម្រង់ Comment មួយ ហើយនិយាយវាឡើងវិញញឹកញាប់៖

កូដ + ទំហំ + ពណ៌ ឧទាហរណ៍ «A2 M ខ្មៅ»។

បើទំនិញមួយមានតែទំហំ ឬពណ៌តែមួយ ប្រាប់អ្នកមើលថា «វាយតែកូដបានហើយ» ដើម្បីកុំឲ្យពួកគាត់ស្ទាក់ស្ទើរ។

៤. បង្ហាញកូដឲ្យឃើញច្បាស់ពេលកាន់ទំនិញ

អ្នកមើលខ្លះចូលមកពាក់កណ្ដាល Live ហើយមិនបានឮពេលអ្នកលក់និយាយកូដ។ ដូច្នេះ៖

  • បិទស្លាកកូដធំៗលើទំនិញ ឬលើព្យួរ។
  • កាន់ទំនិញជិតកាមេរ៉ា ហើយនិយាយកូដ ២ ទៅ ៣ ដង។
  • សរសេរកូដ និងតម្លៃលើក្ដារតូចមួយនៅខាងក្រោយ។

ពេលអ្នកមើលឃើញកូដភ្លាម ពួកគាត់កុម្ម៉ង់បានភ្លាម មិនចាំបាច់សួរ «មួយនេះកូដអី?»។
