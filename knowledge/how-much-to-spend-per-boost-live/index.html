សំណួរ-ចម្លើយ

១. Boost Live មួយដង គួរចាយប៉ុន្មាន?

គ្មានលេខត្រឹមត្រូវសម្រាប់គ្រប់ហាងទេ។ ថវិកាគួរចេញពីលេខពីររបស់ហាងបងផ្ទាល់៖

ថវិកា Boost Live = ចំនួន Order គោលដៅ × Cost per Order គោលដៅ

ក្នុងឧទាហរណ៍ បើចង់បាន ១០ Order ហើយ Cost per Order គោលដៅ $3៖ ១០ × $3 = $30 ក្នុងមួយ Live។

២. Cost per Order គោលដៅ $3 នោះ មកពីណា?

ចាប់ផ្ដើមពីលុយដែលនៅសល់ក្នុងមួយ Order មុនដកលុយ Boost៖

  • Gross Profit = $15 − $7 = $8
  • ដកខ្ចប់ និងដឹក៖ $8 − $0.50 − $1.50 = $6

$6 គឺជាបន្ទាត់ខាត។ ចាយ Boost លើស $6 ក្នុងមួយ Order ពេលណា Live នោះខាតភ្លាម។ ក្នុងឧទាហរណ៍ ហាងដាក់គោលដៅ $3 ដើម្បីទុក $3 ជា Contribution Profit។ វិធីគណនាលម្អិតមាននៅ Boost បានប៉ុន្មានទើបមិនខាត?។

៣. គណនា Cost per Order ក្នុងមួយ Live ដោយរបៀបណា?

Cost per Order ក្នុងមួយ Live = លុយ Boost របស់ Live នោះ ÷ ចំនួន Order ដែលបានបញ្ជាក់ (Confirmed) ពី Live នោះ

ឧទាហរណ៍៖ Boost $20 បាន ៨ Order Confirmed → $20 ÷ ៨ = $2.50 ក្នុងមួយ Order។ $2.50 ទាបជាងគោលដៅ $3 ដូច្នេះ Live នេះល្អ។ សូមរាប់តែ Order Confirmed មិនមែនចំនួន Comment ឬ Message ទេ។

៤. Live នោះ ចំណេញពិតប៉ុន្មាន?

បន្តឧទាហរណ៍៖ ៨ Order ដឹកដល់ ហើយភ្ញៀវបង់លុយទាំងអស់ គ្មានកញ្ចប់បដិសេធ។

  • Revenue = ៨ × $15 = $120
  • Product Cost = ៨ × $7 = $56 → Gross Profit = $120 − $56 = $64
  • ខ្ចប់ ៨ × $0.50 = $4 · ដឹក ៨ × $1.50 = $12 · Refused Parcel Loss = $0 · Ad Cost = $20
  • Contribution Profit = $64 − $4 − $12 − $0 − $20 = $28 (ស្មើ $3.50 ក្នុងមួយ Order)

នេះមិនទាន់ជា Net Profit ទេ ព្រោះមិនទាន់ដកថ្លៃផ្ទះ ប្រាក់ខែ និងថ្លៃថេរផ្សេងៗ។
