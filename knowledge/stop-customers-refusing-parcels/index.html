ខ្ចប់រួច ផ្ញើទៅដល់ ភ្ញៀវថាមិនយក? ខាតទាំងថ្លៃដឹក និងពេលវេលា។ មើលវិធីងាយៗ ៤ ការពារ Order បោះបង់ មុន 11.11 ដែល Order ចូលច្រើន។

បងៗ ធ្លាប់ទេ? ភ្ញៀវ Inbox មកកុម្ម៉ង់ យើងខ្ចប់រួច ផ្ញើទៅដល់ ស្រាប់តែភ្ញៀវថា «មិនយកទេ» ឬទូរស័ព្ទមិនលើក។ ឥវ៉ាន់ត្រឡប់មកវិញ បងខាតថ្លៃដឹក ពេលវេលា ហើយទំនិញខ្លះខូចកញ្ចប់ទៀត។

មុន 11.11 Order ចូលច្រើនជាងធម្មតា ហើយ Order បោះបង់ក៏កើនដែរ។ ខាងក្រោមនេះជាវិធីងាយៗ ៤ ដែលហាងតូចធ្វើបានភ្លាម។

ហេតុអ្វីភ្ញៀវមិនទទួល?

ភាគច្រើនមិនមែនមកពីភ្ញៀវអាក្រក់ទេ។ ភ្ញៀវខ្លះកុម្ម៉ង់ពេលរំភើប ហើយភ្លេច។ ខ្លះច្រឡំទំហំ ឬពណ៌។ ខ្លះរង់ចាំយូរពេក ក៏ទៅទិញផេកផ្សេង។ ខ្លះទៀតមិនដឹងថាត្រូវបង់ប៉ុន្មានពេលទទួល។

១. សរុប Order ឲ្យភ្ញៀវបញ្ជាក់មុនខ្ចប់

ពេលភ្ញៀវថា «យក» កុំខ្ចប់ភ្លាម។ ផ្ញើសារសរុបមួយ៖ ទំនិញ ទំហំ ពណ៌ ចំនួន តម្លៃ ថ្លៃដឹក និងតម្លៃសរុបដែលត្រូវបង់ពេលទទួល។ សុំឲ្យភ្ញៀវឆ្លើយ «បាទ» ឬ «ចាស» មុនខ្ចប់។

២. ផ្ញើសារបញ្ជាក់ម្ដងទៀតមុនដឹក

ពេលប្រគល់ឥវ៉ាន់ឲ្យក្រុមហ៊ុនដឹក ផ្ញើសារខ្លីមួយប្រាប់ភ្ញៀវ៖ ឥវ៉ាន់ចេញហើយ ប្រហែលដល់ពេលណា ហើយសុំឲ្យទុកទូរស័ព្ទបើក។ សារនេះរំលឹកភ្ញៀវ ហើយបើភ្ញៀវប្ដូរចិត្ត យើងដឹងមុនឥវ៉ាន់ចេញឆ្ងាយ។

៣. ប្រាប់ថ្ងៃដល់ឲ្យច្បាស់ ហើយដឹកឲ្យលឿន

ភ្ញៀវដែលរង់ចាំយូរ ងាយបោះបង់ជាងគេ។ ប្រាប់ថ្ងៃដល់ឲ្យច្បាស់ ហើយបើយឺត ប្រាប់ភ្ញៀវមុនគេសួរ។ ពេល Order ច្រើនមុន 11.11 ត្រៀមអ្នកខ្ចប់ និងក្រុមហ៊ុនដឹកឲ្យរួចពីមុន ដើម្បីកុំឲ្យ Order សល់ច្រើនថ្ងៃ។

៤. សុំកក់មុន តែពេលចាំបាច់

កុំសុំកក់ពីភ្ញៀវគ្រប់គ្នា ព្រោះភ្ញៀវថ្មីខ្លះខ្លាច ហើយមិនទិញ។ ប្រើតែពេលចាំបាច់៖ ភ្ញៀវថ្មីដែលកុម្ម៉ង់ច្រើន ទំនិញធ្វើតាមទំហំ ឬភ្ញៀវដែលធ្លាប់មិនទទួល។ ផ្ញើ KHQR ហើយប្រាប់ឲ្យច្បាស់ថាប្រាក់កក់នេះកាត់ចេញពីតម្លៃសរុប។
