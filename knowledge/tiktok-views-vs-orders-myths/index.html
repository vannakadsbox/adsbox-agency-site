ការយល់ខុស៖ វីដេអូណា View ច្រើនជាងគេ វីដេអូនោះលក់ដាច់ជាងគេ។

គួរធ្វើវិញ៖ កត់លេខ ៣ រាល់ថ្ងៃ សម្រាប់វីដេអូនីមួយៗ៖ View, Message, Order។ សួរភ្ញៀវពេលបិទ Order ថា «ឃើញពីវីដេអូណា?» ដើម្បីដឹងថា Order មកពីណាពិត។

ការពិត៖ Message ថោក តែភ្ញៀវមិនកុម្ម៉ង់ គឺលុយនៅតែខាត។ ត្រូវមើល Cost per Order។ (អានបន្ថែម៖ Cost per Message និង Cost per Order)

  • វីដេអូ A៖ Cost per Message = $20 ÷ ៤០ = $0.50 · Cost per Order = $20 ÷ ៤ = $5.00
  • វីដេអូ B៖ Cost per Message = $20 ÷ ២៥ = $0.80 · Cost per Order = $20 ÷ ១០ = $2.00

គួរធ្វើវិញ៖ ប្រៀបធៀបវីដេអូដោយ Cost per Order ជានិច្ច មិនមែនដោយ View ឬ Message ទេ។

ការពិត៖ Order មិនមែនជាចំណេញទេ។ ត្រូវដកថ្លៃដើម ខ្ចប់ ដឹក Order ដែលភ្ញៀវមិនទទួល និងលុយ Boost ទើបដឹង Contribution Profit។
