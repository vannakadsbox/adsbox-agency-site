រឿងឧទាហរណ៍ (មិនមែនអតិថិជនពិត)៖ ហាងលក់អាវនារីតាម Facebook មួយនៅភ្នំពេញ លក់អាវមួយឈុត $20។ ម្ចាស់ហាង Boost Post រាល់ថ្ងៃ សារចូលច្រើន Order ក៏ចូល តែចុងសប្ដាហ៍ លុយក្នុងដៃស្ទើរតែគ្មានសល់។

សំណួរដែលគាត់មិនដែលសួរ គឺ៖ «អាវ $20 មួយឈុត ខ្ញុំអាចចាយ Boost បានប៉ុន្មាន ក្នុងមួយ Order ទើបមិនខាត?»។ លេខនោះហៅថា Cost per Order អតិបរមា។ រឿងនេះបង្ហាញវិធីគណនាវា ជំហានម្ដងៗ។

បញ្ហា៖ Cost per Order មើលទៅមិនថ្លៃ តែចំណេញស្ទើរសូន្យ

ឧទាហរណ៍សម្រាប់បង្ហាញវិធីគណនា (មិនមែនទិន្នន័យអតិថិជនពិត)៖ ក្នុងមួយសប្ដាហ៍ ហាងចាយ Boost $75 បាន Order បញ្ជាក់ ១០។ ក្នុងនោះ ដឹកដល់ហើយបានលុយ ៩ ហើយភ្ញៀវមិនទទួល ១។

Cost per Order = លុយ Boost ÷ Order បញ្ជាក់ = $75 ÷ ១០ = $7.50។ ម្ចាស់ហាងគិតថា «អាវ $20 ចាយ $7.50 មិនអីទេ»។ តែគាត់មិនដែលដឹងថា បន្ទាត់ខាត នៅត្រឹមណា។

អ្វីដែលគាត់ពិនិត្យ៖ លុយនៅសល់ប៉ុន្មាន មុនដកលុយ Boost

គាត់តាមលុយតាមផ្លូវនេះ៖ លុយចាយ → Message → Order → Confirmed → Delivered → Paid → Profit។ ឧទាហរណ៍នេះសន្មត់ថា ថ្លៃដើមអាវ $9 ថ្លៃខ្ចប់ $0.50 ហាងចេញថ្លៃដឹក $1.50 ហើយកញ្ចប់មិនទទួល ត្រូវបង់ថ្លៃដឹកត្រឡប់ $1.50 ទៀត (អាវត្រឡប់ចូលស្តុកវិញ)។

គិតលើ Order បញ្ជាក់ ១០ (ដឹកដល់ ៩ មិនទទួល ១)៖

  1. Revenue (លុយបានពីភ្ញៀវ)៖ ៩ × $20 = $180
  2. Gross Profit = Revenue − ថ្លៃដើម៖ $180 − (៩ × $9 = $81) = $99
  3. ថ្លៃខ្ចប់ Order ដឹកដល់៖ ៩ × $0.50 = $4.50
  4. ថ្លៃដឹក Order ដឹកដល់៖ ៩ × $1.50 = $13.50
  5. Refused Parcel Loss៖ ១ × ($0.50 + $1.50 + $1.50) = $3.50
  6. លុយនៅសល់ មុនដកលុយ Boost៖ $99 − $4.50 − $13.50 − $3.50 = $77.50

ចែកនឹង Order បញ្ជាក់៖ $77.50 ÷ ១០ = $7.75។ នេះហើយ Cost per Order អតិបរមា៖ បើចាយ Boost ដល់ $7.75 ក្នុងមួយ Order បញ្ជាក់ នោះ Contribution Profit នៅសល់ $0។

ចាយ $7.50 មានន័យថា ចំណេញតែ $0.25 ក្នុងមួយ Order។ ពិនិត្យ៖ $77.50 − $75 = $2.50 ក្នុងមួយសប្ដាហ៍ = ១០ × $0.25។ ត្រូវគ្នា។ នេះមុនដកថ្លៃផ្ទះ ប្រាក់ខែ និងថ្លៃថេរផ្សេងៗទៀត ដូច្នេះ Net Profit គឺខាតហើយ។

អ្វីដែលប្ដូរ៖ ដាក់លេខពីរ ជំនួសការទាយ

  • ចំណេញដែលចង់បាន៖ ៩ × $4 = $36
  • លុយ Boost ដែលអាចចាយបាន៖ $77.50 − $36 = $41.50
  • Cost per Order គោលដៅ៖ $41.50 ÷ ១០ = $4.15
